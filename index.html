러브캐피털 (LoveCapital)

개인 게임 개발 프로젝트용 Google Drive 연결 앱

무엇인가요

이 앱은 프로젝트 소유자 한 사람이 자기 Google Drive에 개발 파일을 보관하려고 만든 개인용 OAuth 클라이언트입니다. 오픈소스 파일 동기화 도구 rclone이 이 클라이언트로 Drive에 연결합니다.

  • 보관하는 것: 게임 개발 저장소 백업, 빌드 결과물, 작업 중 이미지 같은 프로젝트 파일
  • 쓰는 사람: 프로젝트 소유자 본인뿐입니다. 다른 사용자에게 제공하지 않습니다.
  • 접근 범위: drive.file — 이 앱이 직접 만든 파일만 보고 쓸 수 있습니다. Drive의 다른 파일은 볼 수 없습니다.

개인정보처리방침

개인정보처리방침 보기 (Privacy Policy)

LoveCapital is a personal OAuth client used only by the project owner to store their own game-development files (repository backups, build outputs, work-in-progress images) in their own Google Drive through rclone. It requests only the drive.file scope and is not offered to other users. See the Privacy Policy.
