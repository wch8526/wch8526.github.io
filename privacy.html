개인정보처리방침

러브캐피털 (LoveCapital) · 시행일 2026-10-07

1. 접근하는 데이터

이 앱은 Google의 drive.file 범위만 요청합니다. 그래서 이 앱이 직접 만든 Drive 파일과 폴더만 읽고 쓸 수 있습니다. 사용자의 다른 Drive 파일, Gmail, 연락처, 프로필 정보에는 접근하지 않습니다.

2. 데이터를 쓰는 목적

프로젝트 소유자가 자기 게임 개발 파일(저장소 백업, 빌드 결과물, 작업 이미지)을 자기 Drive에 올리고 다시 받는 데에만 씁니다. 광고, 분석, 프로파일링, 판매에는 쓰지 않습니다.

3. 저장과 공유

  • 파일은 사용자 본인의 Google Drive에만 저장됩니다. 이 앱은 별도 서버를 운영하지 않습니다.
  • 접근 토큰은 사용자 본인 컴퓨터의 rclone 설정에만 저장됩니다.
  • 데이터를 제3자에게 판매하거나 공유하지 않습니다.

4. 접근 철회와 삭제

언제든 Google 계정 → 타사 앱 및 서비스에서 이 앱의 접근을 삭제할 수 있습니다. 이 앱이 만든 파일은 Google Drive에서 직접 지울 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 쓰고 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 문의

이 페이지가 있는 GitHub 저장소(wch8526/wch8526.github.io)로 문의할 수 있습니다.

Privacy Policy (English summary)

LoveCapital requests only the Google drive.file scope, so it can read and write only files it created in the user's Google Drive. It is used solely by the project owner to back up and retrieve their own game-development files. Files stay in the user's own Google Drive; access tokens stay in the local rclone configuration on the user's computer. No data is sold, shared with third parties, or used for advertising or analytics. Access can be revoked at any time at Google Account → Third-party apps & services. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
